# Портфолио по анализу данных

Учебные проекты на Python. В каждой папке отдельный проект со своим описанием.

| Проект | О чем | Что использовал |
|---|---|---|
| [Титаник](titanic/) | Исследовательский анализ: от чего зависела выживаемость пассажиров | pandas, KNN, z-тест, логистическая регрессия |
| [A/B-тест](ab_test/) | Дизайн эксперимента, расчет MDE и длительности теста | pandas, statsmodels, линеаризация |
| [Гисметео](gismeteo/) | Парсинг прогноза погоды и подбор лучших недель для отпуска | requests, BeautifulSoup, seaborn |
